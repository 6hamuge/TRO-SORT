## 가림 위치 이력 가설 1차 검증 결과 공유 및 개선 방향 질문

재현 OA-SORT를 기준선으로, 계획서의 가설(가림 영역의 상대 위치와 그 시간 변화가 ID 유지에 도움이 된다)을 먼저 검증해 봤습니다.
자세한 내용은 PR #<번호>의 `occflow/docs/report.md`에 있습니다.

**범위:** 추적 실험은 리뷰에서 지목된 dancetrack0026과 0079 두 시퀀스, 오라클(GT 박스만 사용)은 val 전체 25개입니다.
추적 지표는 두 시퀀스 합산이라 val 전체 기준선(HOTA 60.24)과 직접 비교할 수 없습니다.
새 모듈을 끈 상태(효과 0)의 출력은 재현 OA-SORT와 완전히 같은 것도 확인했습니다.

### 결과 요약
1. **실패 위치:** 재현 OA-SORT의 ID 오류 중 **93%가 3명 이상이 겹친 상황**에서 생깁니다.
   두 사람만 교차하는 경우는 7%이고, 교차와 무관한 오류는 0건이었습니다.
   FN의 78%(846 / 1085)는 같은 위치에 고신뢰 검출이 있었습니다.
2. **가설 검증:** 교집합 위치 이력을 1차 매칭 비용에 넣으면 IDSW는 156 → 148로 줄지만,
   HOTA는 66.65 → 65.95, AssA는 55.36 → 54.34로 떨어집니다.
   흐름 항이 바꾼 결정 48건을 GT로 보면 고침 19건, 망침 18건으로 반반이었습니다.
3. **오라클:** GT 박스만 써서 추적기 잡음을 없애도, 가림 위치 이력은 모든 조건에서 단순 직선 운동 예측보다 낮았습니다.
   관측 공백 10프레임 기준으로 0.896 대 0.921입니다.
   교집합 위치는 두 박스 좌표에서 계산되는 값이라, 그 시간 변화는 상대 운동과 거의 같은 정보로 보입니다.
4. **판단 보류:** 교차 중에는 ID를 미루고 흩어진 뒤 양방향으로 다시 잇는 방식도 시험했습니다.
   GT에서는 효과가 있었지만, 실제 결과에서는 고친 경우가 0건이었습니다.
   오류가 나는 뭉침은 정해진 시간 안에 흩어지지 않아 판단 대상에 들어오지 못했습니다.

### 다음 방향 (교수님 피드백 반영)
- 뭉치기 직전 각 사람의 attribute(외형 임베딩, 색, 크기 등)를 저장하고, 흩어진 뒤 그걸로 대응을 다시 정하기
- 3명 이상 겹치는 동안은 confusion mode로 표시하고, memory limit 안에서 후보 집합으로 묶어 두기
- 장기간 ID를 유지하는 기존 방법(long-term memory, 외형 갤러리, 트랙렛 연결 등) 조사
- 추적기에 넣기 전에, attribute로 순열을 고르는 정확도를 GT 오라클로 먼저 확인

### 의견 부탁드립니다
1. 이번 결과로 보면 박스 위치·운동만으로는 뭉침 오류를 풀기 어려워 보입니다.
   가설을 attribute(외형) 결합 쪽으로 바꾸는 것에 동의하시는지, 아니면 박스만 쓰는 경량 접근을 유지할 다른 방법이 있을지 궁금합니다.
2. 비교 실험으로 "운동만 쓴 대조군"을 추가하는 게 맞을지 의견 부탁드립니다.
   계획서 6장의 B/C 비교만으로는 시간적 이력이 운동과 다른 정보를 주는지 구분하기 어렵습니다.
3. FN의 78%가 검출은 있는데 출력에서 빠진 것인데, 이 부분(재생성 대기, 연결 실패)을 따로 분석해 볼 만한지,
   아니면 재현 코드 쪽 문제일 가능성도 있을지 확인 부탁드립니다.
4. long-term memory나 attribute 기반으로 참고할 만한 논문을 알고 계시면 공유 부탁드립니다.
