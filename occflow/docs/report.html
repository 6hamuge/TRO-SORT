해석

모든 공백에서 운동 예측이 앞섰고, 박스에 3% 잡음을 넣어도 같았습니다. 운동 예측이 틀린 프레임에서 이력이 맞힌 비율은 36~37%입니다. 교집합 위치는 두 박스 좌표에서 그대로 계산되므로, 그 추세를 연장하는 것은 두 사람의 궤적을 각각 연장하는 것과 거의 같습니다. 계획서 6장의 B/C 비교만으로는 이 점을 가를 수 없어서, 운동만 쓴 대조군이 필요합니다.

5. 다음 방향

교수님 피드백

  • history를 쓴다면 관련 최신 논문 정리, 장기간 ID를 유지할 때 기존 방법은 어떻게 하는지 (long-term memory)
  • 장기 기억을 sliding window로 따라가기, 수학적 모델로 결과가 나오는지
  • memory limit을 두고 오류가 생기면 condition/confusion mode로 전환
  • 분리될 때 각각의 attribute를 저장, 여러 명이 겹칠 때 attribute를 어떻게 저장할지, 3명이 되어도 찾아낼 수 있는지
  • 뭉치기 직전 attribute 저장 → 흩어진 뒤 대조. 운동으로 구분이 안 되는 그림 C 같은 구간에 직접 대응합니다. 외형 임베딩(Hybrid-SORT의 ReID 옵션), 색 분포, 박스 크기·비율이 후보입니다. 판단 보류 구조는 그대로 두고 연결 비용만 바꾸면 바로 시험할 수 있습니다.
  • confusion mode. 3명 이상 겹치는 동안 관련 트랙을 하나의 후보 집합으로 묶어 두고, 흩어지면 저장된 attribute로 대응을 다시 정합니다. memory limit은 혼동 상태의 최대 지속 시간과 저장 개수로 둡니다.
  • long-term memory 조사. 외형 갤러리를 길게 유지하는 방식, 외형의 지수이동평균, 메모리 뱅크 기반 추적기, 오프라인 트랙렛 연결을 비교합니다.
  • 검증 순서. 이번처럼 GT 오라클로 먼저 판별력을 확인합니다. attribute로 대응을 고르는 정확도가 운동보다 높은지, 특히 3명 이상에서 어떤지 본 뒤 추적기에 넣습니다.

의견을 구합니다

  1. 박스 위치·운동만으로는 뭉침 오류를 풀기 어려워 보입니다. 가설을 attribute(외형) 결합 쪽으로 바꾸는 데 동의하시나요? 박스만 쓰는 경량 접근을 유지할 다른 방법이 있을까요?
  2. 비교 실험에 "운동만 쓴 대조군"을 추가하는 게 맞을까요?
  3. FN의 78%가 검출은 있는데 출력에서 빠진 경우입니다. 따로 분석할 만한지, 재현 코드 쪽 문제일 가능성은 없는지 확인 부탁드립니다.
  4. long-term memory나 attribute 기반으로 참고할 논문을 알고 계시면 공유 부탁드립니다.
